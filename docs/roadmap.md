# 路线图

## 已完成（v0.2，本次重构）

- skill + references；`vh` CLI（状态推导、闸门、配音、html 预渲染、渲染、复核、比对、合成评测）；薄 MCP 适配器。
- `packages/core`：场景图、设计包 `illustrated`（day / night / sepia 章节）、闭式动效数学、5 个场景级积木、分镜 v2 schema、版面校验（H4–H8）。
- `packages/runtime`：场景图 SVG 渲染器（渐变、辉光、虚拟相机、视差、参数化角色、暗角、颗粒）、转场、配音 + 配乐 ducking。
- `analyze/`：版式感知切镜、视觉节拍、旁白锚定、调色板、多片聚合、rea-video 合并、合成集打分。
- 示例 `examples/sky-blue`（积木 + local 场景图 + html 镜头，ElevenLabs 配音）。

## 下一步（建议顺序）

1. **积木扩充**（按节拍里最常出现的视觉想法）：分屏 / 对比、时间轴 + 进度条、地图、点阵大数字、线框人体 / 器官图、章节回顾蒙太奇、闪回滤镜。
2. **角色系统**：更多体型与配件、口型跟随语音（`voice.json` 逐词时间）、手势。
3. **分析扩展**（docs/decisions D7）：2D 动画识别特征（插画纹理、非刚体形变、分层视差、有限帧节奏）；元素轨迹 → 积木参数 → 分镜草稿；字幕判定（OCR 文字与同时刻语音一致）。版式感知与字幕判定整理成 PR 回馈 rea-video。
4. **评测**：扩大合成集（转场、相机运动、html 镜头）；平台压缩变体；真实视频留出集（每类 3–5 条，人工看图标注）；awesome-opus5-5-videos 中纯代码条目作为生成端题库。
5. **音频**：配乐与音效轨（节拍对齐到画面事件）、字幕导出（SRT）。
6. **记忆**：用户纠正与 A/B 偏好记录（`corrections.jsonl`），积累后转成评测样本。

## 已知限制

- 场景图文字宽度是估算，版面校验对极端字体可能有 ±10% 误差。
- react 镜头没有场景图，不参与版面校验。
- 当前合成集只覆盖内置积木，分析在真实视频上的指标以 `eval/RESULTS.md` 为准。
