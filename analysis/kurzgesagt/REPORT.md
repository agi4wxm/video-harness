**数据说明了什么：**

1. **节奏是"呼吸式"的。** 旁白每分钟停顿 21 次。画面变化有 44% 落在停顿里，对齐短语边界的程度是差评君的 1.5 倍：话说完一句、换口气，画面才换。段时长中位 3.4s，每个画面停得更久、信息更足。差评君的节奏是"字不停、图不停"，两者是完全不同的节奏哲学。
2. **颜色是演示片廉价感最大的单一来源。** Kurzgesagt 的彩度是演示片的 **14 倍**，亮度是演示片的 2.7 倍。演示片的色彩数据实际上接近灰度。
3. **文字很少。** 只有 35% 的时间画面上有字，而且都是指向物体的小标签，没有字幕。信息靠画面传达，不靠读字。
4. **不卡音乐节拍。** 和差评君一样，画面跟着旁白走，不跟着音乐走。

## 3. 设计体系（定性）

### 3.1 造型
- 扁平矢量插画，**没有描边**；几何形体都是圆角；角色头大、眼睛圆，表情丰富。
- 质感来自**柔和渐变 + 发光（bloom）+ 轮廓光**，而不是纹理。重要的物体（药物、癌细胞、发光的身体）都有霓虹般的辉光。
- 屏幕上的元素都"是某个东西"：器官、细胞、分子、针管、小鼠、人群。几乎看不到纯抽象的框和箭头。

### 3.2 色彩：按章节换色，按语义编码
- **全片调色板**：奶油底 `#EFEEC9`（占 31%，标志性底色）、深紫 `#6126A0`、洋红 `#DB558D`、梅紫 `#401948`、藏青 `#0D0A60`、长春花蓝 `#6474D2`、薄荷绿 `#57D88C`。
- **章节色温**：
  - 个人故事：暖奶油、黄色；
  - 历史闪回：棕褐色调，加复古电视画框、颗粒和暗角；
  - 体内机制：深紫、藏青、洋红。

  换章节，就换一整套颜色。
- **语义编码**：药物顺铂从头到尾都是霓虹绿（输液袋、分子、发光的身体）；癌细胞是红蓝配色；主角皮肤是粉色。观众不读字也知道画面里谁是谁。

### 3.3 角色与拟人
- 有一个贯穿全片的主角（讲述者本人）和吉祥物小蓝鸟。
- 器官、细胞、分子都被**拟人化**：会皱眉的肾、长着大眼睛的癌细胞、像小工人一样的修复分子。情绪是靠角色的表情传达的。

## 6. 每个画面的"视觉想法"

数据和抽象概念都被画成**具体的东西**：

| 概念 | 画法 |
|---|---|
| 生存率 | 一群小人中有多少变成了绿色；满屏点阵 32% → 95% 加大字 |
| 剂量实验 | 一排针管对应一排小鼠，小鼠的状态随剂量变化 |
| 疗程进度 | 人体图 + 底部按周的进度条，病灶逐个熄灭 |
| 药物在体内流动 | 身体变成发光的线框网格 |
| 程序性细胞死亡 | 倒计时的秒表 |
| DNA 修复 | 修复分子像小工人一样在 DNA 上干活 |
| 可信度 | 角落里的小字文献引用（如 Rosenberg et al. 1965） |

## 7. 对 harness 的结论

这次分析印证了上一轮的判断，并且给出了**可执行**的方向：

1. **风格包要换成"插画世界"体系。** 每章一套调色板，有语义颜色映射和发光规则；底色明亮；高彩度（C 中位 ≥ 0.08）。
2. **积木要从"界面组件"升级为"场景组件"**：
   - 插画场景 + 虚拟相机（推拉摇移、尺度穿越）；
   - 带待机呼吸动作和表情的角色；
   - 人群单位图、点阵大数字；
   - 章节标题卡、闪回滤镜、分屏。
3. **节奏规则（横屏讲解类）**：
   - 段时长中位 3–4s；
   - 视觉边界 12–18 次 / 分钟；
   - 至少 40% 的视觉边界落在旁白停顿里；
   - 短语对齐倍数 ≥ 1.5；
   - 旁白要留出停顿（TTS 需要控制停顿）。
4. **文字规则**：有字的时间 ≤ 40%，以指向物体的标签为主；数字用大字排版。
5. **分镜阶段必须先写"视觉想法"**：每个节拍要画什么具体的东西、用什么隐喻、哪个母题会反复出现。这一步是创意的核心，必须在写代码之前完成。
6. **素材来源**：需要一套风格统一的插画素材（SVG、角色组件）。可以用生成模型按我们自己的风格说明批量生成后矢量化，但**不复刻 Kurzgesagt 的角色和视觉标识**。借鉴的是原则：扁平、无描边、发光、语义配色、拟人化，不是具体形象。

## 8. 局限

- 只有 1 条视频。同一个频道多看几条，才能区分哪些是频道风格、哪些是这一集的选择。
- 声音只测了响度和节拍。配乐、音效与画面的配合，是 Kurzgesagt 质感的重要来源，还需要单独分析。
- 镜头运动（推拉摇移）目前只能靠目测，测量工具还不能自动识别运镜类型。
