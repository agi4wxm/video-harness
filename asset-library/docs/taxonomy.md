# 素材分类体系

> 由 `packages/core/src/taxonomy.ts` 自动生成（`lib docs`），请勿手改。共 8 大类、46 小类。

## 归类决策树（互斥且穷尽）

依次回答，第一个「是」决定大类；全部为「否」时，它是画面里出现的「东西」，归画面内容，再按媒介形态选小类。

1. **它是对一整条参考视频的拆解记录吗？** → `reference`
   - 不是视频里的某个要素，而是把一条视频拆开后的总记录。
   - 小类：`video`（一条参考视频）
2. **它是视频之外的知识或文字信息吗（事实、数字、出处、引语、概念、人物、事件）？** → `knowledge`
   - 问：去掉画面和声音，它还作为'信息'存在吗？例如'800 公斤'这个数字本身。它在画面上的样子另归 content。
   - 小类：`source`（可引用的出处）、`fact`（可核查的结论 / 数字）、`quote`（某人的原话）、`concept`（要解释的概念与类比）、`person-org`（真实人物或机构）、`event`（有日期的事件）
3. **它是听到的吗？** → `sound`
   - 人声、音乐、音效、环境声。字幕是看到的文字，不算声音。
   - 小类：`voice`（人声（旁白、对白、配音））、`music`（有旋律或节奏的音乐）、`ambience`（持续的环境底噪）、`sfx`（其余点状声音）
4. **它是组织时间的东西吗（跨越多个镜头：段落顺序、节奏、剪辑逻辑）？** → `structure`
   - 单个镜头里看不出来，要看一段时间才能看出来。转场的'视觉样式'归 effect，'为什么在这里切'归 structure。
   - 小类：`narrative`（整片段落顺序）、`segment`（可复用的局部结构）、`rhythm`（节奏的数值规则）、`edit`（剪辑手法）
5. **它是一组规则或参数，而不是具体可见的东西吗（配色、字体规范、版式、动效语言、调色）？** → `style`
   - 它约束很多素材的样子，本身不出现在画面上。
   - 小类：`pack`（一整套风格）、`palette`（颜色）、`type-system`（文字规范）、`layout`（构图与分区）、`motion-language`（运动规则）、`grade`（调色与质感）
6. **它是驱动画面的数据或公式本身吗（仿真输出、数据表、公式、地理数据）？** → `data`
   - 同一份数据可以被 3D、曲线、读数同时使用。数据画成的图形另归 content.chart。
   - 小类：`simulation`（可运行模型及其输出）、`dataset`（表格 / 时间序列）、`formula`（公式与推导）、`geo`（地理数据）
7. **它是一种'变化或处理'，而不是一个'东西'吗（怎么出现、怎么动、镜头怎么动、怎么转场、怎么叠加、怎么渲染、后期）？** → `effect`
   - 可以把同一个效果套在不同的东西上。
   - 小类：`element-motion`（单个元素的动作）、`text-motion`（文字的动作）、`dataviz`（数据驱动的动画）、`camera`（机位运动）、`transition`（镜头之间的过渡）、`overlay`（多层画面的组合方式）、`render3d`（3D 特有的表现）、`particle`（粒子 / 程序化特效）、`post`（整体画面处理）
8. **以上全否** → `content`，按媒介形态：`model3d`（单个 3D 资产）、`scene3d`（多个 3D 资产 + 环境 + 灯光的装配）、`material`（材质、贴图、环境贴图）、`chart`（绑定数据的图表）、`ui`（界面、面板、卡片）、`typography`（文字设计）、`font`（字体文件）、`brand`（logo、商标、水印）、`animation`（自带时间轴的预制动画）、`vector`（其他矢量图形）、`footage`（视频片段）、`image`（其他位图）

## 知识素材 · `knowledge`

视频之外的信息：资料来源、事实与数据点、引语、概念与类比、人物与机构、事件。是脚本的原料。

### 资料来源 · `knowledge.source`

论文、书籍、报道、网页、访谈、官方文件等可被引用的出处。

- **例子**：1964 年 Meditch 登月软着陆论文；SpaceX 工程师撰写的技术文章；百科词条；专家访谈录音
- **存储**：kind（paper/book/article/web/interview/document/video）；标题、作者、年份；链接或 DOI；可靠性评级；本地存档（PDF / 网页快照）
- **提交审查必填**：`spec.kind`、`spec.title`、`spec.reliability`
- **制作路线**：检索、人工整理

### 事实与数据点 · `knowledge.fact`

一条可核查的结论或数字，必须附出处。

- **例子**：小车重 800 公斤；方案二用气约 44 公斤；蓝光散射强度约为红光 5.5 倍
- **存储**：结论原文；数值与单位；出处（source 引用）；可信度；核查人与核查日期
- **提交审查必填**：`spec.claim`、`spec.sources`、`spec.confidence`
- **制作路线**：检索、计算、仿真复现

### 引语 · `knowledge.quote`

某人说过或写过的原话，含原文与译文。

- **例子**：“每悬停一秒，都是在浪费推进剂”；电影台词；采访金句
- **存储**：原文；译文；说话人；出处与日期
- **提交审查必填**：`spec.text`、`spec.speaker`、`spec.source`
- **制作路线**：检索

### 概念与类比 · `knowledge.concept`

需要被讲清楚的概念，以及解释它的类比和可视化想法。

- **例子**：哈密顿量 = 此刻代价率 + 协态 × 状态变化率；开关函数；瑞利散射
- **存储**：术语；通俗解释；类比；可视化想法（画面构思）；前置概念
- **提交审查必填**：`spec.term`、`spec.explanation`
- **制作路线**：检索、写作

### 人物与机构 · `knowledge.person-org`

出现在视频里的真实人物、团队、公司、机构。

- **例子**：庞特里亚金（1908–1988）；Lars Blackmore · SpaceX；NASA
- **存储**：名称；身份与头衔；生卒或成立年份；可用肖像 / 标识的授权情况
- **提交审查必填**：`spec.name`、`spec.role`、`spec.image_rights`
- **制作路线**：检索

### 事件与时间线 · `knowledge.event`

有日期的事件，用于时间线、历史佐证。

- **例子**：1956 年极小值原理提出；2016 年首次海上回收；阿波罗登月
- **存储**：日期；标题；描述；出处
- **提交审查必填**：`spec.date`、`spec.title`、`spec.sources`
- **制作路线**：检索

## 风格 · `style`

规定素材"长什么样、怎么动"的规则与参数，不是具体可见的东西。

### 风格包 · `style.pack`

一套完整风格：引用色板、字体规范、版式、动效语言、调色，附风格帧与禁用清单。

- **例子**：仿真讲解 · 深色数学黑板 + 写实 3D；插画科普 · 明亮奶油底；赛博朋克广告
- **存储**：引用的 palette / type-system / layout / motion-language / grade；场景基调；材质语言；禁用清单；风格帧（图）；参考关键帧
- **提交审查必填**：`spec.palette`、`spec.frames`、`spec.banned`
- **制作路线**：拆解参考视频、设计

### 色板 · `style.palette`

颜色 token、语义与章节色板。

- **例子**：黄=最优 / 关注，浅蓝=对照，橙红=超标；品牌色板；电影调色板
- **存储**：颜色列表（token、hex、含义）；章节变体；对比度检查结果
- **提交审查必填**：`spec.colors`
- **制作路线**：拆解取色、设计

### 字体排版规范 · `style.type-system`

各类文字用什么字体、字重、字号、行距、强调方式。

- **例子**：粗黑体章节标签 + LaTeX 公式 + 等宽数字；杂志风衬线标题
- **存储**：角色 → 字体（引用 content.font）；字号阶梯（占画面高度比例）；强调规则
- **提交审查必填**：`spec.roles`、`spec.scale`
- **制作路线**：拆解、设计

### 版式与构图 · `style.layout`

画面分区、网格、安全区，以及各元素的固定位置。

- **例子**：左上章节标签 + 右侧 HUD + 底部字幕；竖屏窗口版式；三分法构图规则
- **存储**：画布尺寸与比例；安全区；分区（名称 + 位置）；示意图
- **提交审查必填**：`spec.canvas`、`spec.zones`
- **制作路线**：拆解、设计

### 动效语言 · `style.motion-language`

全片统一的运动规则：时长、缓动、间隔、强调方式、运动原则。

- **例子**：入场 0.4s 缓出、逐项间隔 80ms；弹性 UI 动效规范；迪士尼动画原则子集
- **存储**：时长；缓动曲线；逐个间隔；强调规则；禁用动作
- **提交审查必填**：`spec.durations`、`spec.easing`
- **制作路线**：拆解测量、设计

### 调色与质感 · `style.grade`

整体色调、对比、饱和度、颗粒、暗角等质感规则（实现见 effect.post）。

- **例子**：暗场高对比 + 冷色；胶片暖调 + 颗粒；明亮低对比插画质感
- **存储**：对比度 / 饱和度 / 色温目标；颗粒与暗角强度；LUT 引用；前后对比图
- **提交审查必填**：`spec.targets`
- **制作路线**：拆解测量、设计

## 画面内容 · `content`

画面里出现的"东西"，按媒介形态分：3D、矢量、位图、视频、预制动画、文字、字体、界面、图表、标识。

### 3D 模型 · `content.model3d`

物体、角色、道具、载具、建筑等单个 3D 资产。

- **例子**：可拆开气罐与阀门的微型车；登月舱；可回收火箭；游戏角色；产品模型
- **存储**：模型文件（glb）；源文件（可选）；部件清单（命名节点 + 可动方式）；材质变体（写实 / X 光 / 线稿）；单位、朝向、原点、面数；骨骼与动画片段；转台预览
- **提交审查必填**：`spec.format`、`spec.units`、`spec.parts`
- **制作路线**：授权模型改造、程序化建模、Three.js

### 3D 场景 · `content.scene3d`

由多个模型、环境、灯光、机位组成的场景装配。

- **例子**：白天城市高架 + 斑马线；太空背景；产品摄影棚
- **存储**：摆放清单（引用 model3d@版本 + 位姿）；环境贴图；灯光预设；机位预设；场景预览
- **提交审查必填**：`spec.placements`、`spec.lighting`
- **制作路线**：Three.js 装配

### 材质与贴图 · `content.material`

PBR 材质、贴图、环境贴图（HDRI）、matcap。

- **例子**：沥青路面 PBR；城市天空 HDRI；X 光青色半透明材质；纸张纹理
- **存储**：类型；各通道贴图（basecolor/normal/roughness…）；分辨率；无缝与否；预览球
- **提交审查必填**：`spec.kind`、`spec.resolution`
- **制作路线**：授权素材、程序化生成、图像生成

### 矢量图形 · `content.vector`

图标、插画、示意图、2D 角色、地图、图案等矢量资产。

- **例子**：车辆侧视示意图；气罐液位图标；阀门编号点；扁平插画角色；地图轮廓；流程示意图
- **存储**：分层命名的 SVG；可调参数（如液位）；状态变体；对齐 / 连接点；多尺寸预览
- **提交审查必填**：`spec.kind`、`spec.layers`
- **制作路线**：手写 SVG、矢量化

### 图表组件 · `content.chart`

绑定数据的参数化图形：曲线、柱状、热力图、坐标轴、仪表。

- **例子**：阀门开度热力图；用气曲线 + 面积填充；轨迹族坐标图；股价 K 线
- **存储**：图表类型；数据绑定（通道 → 视觉通道）；坐标轴与刻度规则；样式 token；示例数据预览
- **提交审查必填**：`spec.chart_type`、`spec.bindings`
- **制作路线**：SVG + 数据

### 界面与面板 · `content.ui`

HUD、信息卡片、窗口、屏幕界面、按钮等界面类组合元素。

- **例子**：右侧半透明遥测 HUD；GitHub 仓库卡片；手机 App 界面；游戏 UI
- **存储**：组件结构（子元素引用）；可变字段；状态；尺寸与锚点；预览
- **提交审查必填**：`spec.kind`、`spec.fields`
- **制作路线**：SVG / HTML 组件

### 位图图像 · `content.image`

照片、生成图、截图、扫描件等位图。

- **例子**：火箭着陆写实画面（生成）；多角度拍车照片；论文页面；人物肖像（授权）；产品摄影
- **存储**：原图；生成记录（模型、提示词、参数）或拍摄 / 授权信息；分层或深度图（用于视差）；安全裁切区；是否涉及真实人物 / 品牌
- **提交审查必填**：`spec.kind`、`spec.dimensions`
- **制作路线**：OpenAI 图像生成、授权图库、自行排版

### 视频片段 · `content.footage`

实拍、生成、录屏、渲染出来的视频片段。

- **例子**：火箭着陆实拍；仿真渲染片段；软件操作录屏；航拍空镜；访谈画面
- **存储**：视频文件；时长、帧率、分辨率；有无音轨；来源与授权；可用区间（入点 / 出点）；关键帧拼图
- **提交审查必填**：`spec.kind`、`spec.duration`、`spec.fps`
- **制作路线**：渲染输出、授权素材、录屏

### 预制动画 · `content.animation`

自带时间轴的动画资产：Lottie、Rive、序列帧、GIF。

- **例子**：加载动画 Lottie；角色挥手序列帧；图标动效
- **存储**：动画文件；时长、帧率、是否循环；可控参数；确定性检查（能否按帧定位）
- **提交审查必填**：`spec.format`、`spec.duration`
- **制作路线**：Lottie / 序列帧

### 文字元素 · `content.typography`

画面中的文字设计：标题、大字、字幕样式、人名条、金句卡、公式样式、标签、标注。

- **例子**：大字「数学」；章节标签；底部字幕 + 黄色关键词；人名条；中英双语金句卡；LaTeX 公式排版；年份大字
- **存储**：模板代码；参数（文字、高亮词、语言）；使用的字体（引用 content.font）；多尺寸预览
- **提交审查必填**：`spec.kind`、`spec.fonts`
- **制作路线**：SVG / MG 模板、KaTeX

### 字体 · `content.font`

字体文件及其授权。

- **例子**：思源黑体；Inter；JetBrains Mono；KaTeX 数学字体
- **存储**：字体文件；字族与字重；支持的文字（中 / 英 / 数学）；授权
- **提交审查必填**：`spec.family`、`spec.license`
- **制作路线**：开源字体、授权字体

### 标识 · `content.brand`

logo、商标、水印、吉祥物等身份类素材，必须登记权利。

- **例子**：频道 logo；GitHub 标志；合作方商标；节目水印
- **存储**：文件（矢量优先）；所有者；使用授权与限制；最小尺寸与留白规则
- **提交审查必填**：`spec.owner`、`spec.rights`
- **制作路线**：用户提供、官方素材包

## 数据 · `data`

驱动画面的数据与公式：仿真、数据集、公式、地理数据。画面、读数、曲线都从这里取值，保证一致。

### 仿真 · `data.simulation`

可运行、确定性的模型及其输出（轨迹、控制量、状态量）。

- **例子**：汽车软着陆 MPC 仿真；几百次随机初值的轨迹；种群演化模拟；流体模拟
- **存储**：仿真代码（带种子）；参数；每次运行的输出数据；数据字典（通道、单位、频率）；合理性校验；曲线 / 轨迹预览
- **提交审查必填**：`spec.params`、`spec.channels`
- **制作路线**：Python / JS 仿真

### 数据集 · `data.dataset`

外部或整理出来的表格 / 时间序列数据。

- **例子**：历年火箭回收次数；城市人口统计；实验测量数据
- **存储**：数据文件；列定义与单位；来源与授权；更新日期；预览图
- **提交审查必填**：`spec.columns`、`spec.source`
- **制作路线**：下载、整理

### 公式 · `data.formula`

公式本身（内容），含变量含义与推导步骤；排版样式见 content.typography。

- **例子**：J = Φ(v_T, θ_T) + ∫ ℓ(v) dt；H = S(t)·u + H₀；伯努利方程
- **存储**：LaTeX；变量含义；推导步骤（逐项追加顺序）；出处
- **提交审查必填**：`spec.latex`、`spec.variables`
- **制作路线**：整理、推导

### 地理数据 · `data.geo`

地图边界、路线、坐标点等地理数据。

- **例子**：发射场坐标；国家边界 GeoJSON；航线
- **存储**：GeoJSON / TopoJSON；投影；来源与授权
- **提交审查必填**：`spec.format`、`spec.source`
- **制作路线**：开放数据

## 呈现效果 · `effect`

"变化与处理"：东西怎么出现、怎么动，镜头怎么动，画面怎么转场、叠加、渲染和后期。每个效果都是可调参数的代码 + 样片。

### 元素动效 · `effect.element-motion`

单个元素的入场、退场、强调、变形、计数等动作。

- **例子**：弹出入场；数字滚动计数；关键项脉冲强调；图形变形；描线绘制
- **存储**：实现代码（运行环境）；参数与默认值；插槽（需要的素材）；节奏（入场 / 停留 / 退场）；样片
- **提交审查必填**：`spec.runtime`、`spec.params`
- **制作路线**：MG / SVG / Three.js

### 文字动效 · `effect.text-motion`

文字特有的动画：逐字打出、打字机、关键词变色、公式逐项追加。

- **例子**：金句逐字打出 + 关键词变色；公式逐项追加并在项下注释；大字砸入；卡拉 OK 字幕
- **存储**：实现代码；参数；插槽（文字元素）；样片
- **提交审查必填**：`spec.runtime`、`spec.params`
- **制作路线**：MG / SVG

### 数据可视化动效 · `effect.dataviz`

数据驱动的动画：曲线描画、轨迹族展开、热力图更新、对比。

- **例子**：一族轨迹展开 + 最优解高亮 + 超标标红；阀门开度矩阵随时间更新；两方案曲线叠加对比
- **存储**：实现代码；数据插槽（通道）；参数；样片
- **提交审查必填**：`spec.runtime`、`spec.data_slots`
- **制作路线**：SVG + 数据

### 镜头运动 · `effect.camera`

虚拟或实拍的机位运动：推拉摇移、环绕、穿越、跟拍、手持晃动。

- **例子**：高速穿过喷管；环绕重建模型；跟拍坠落；缓慢推镜；尺度穿越
- **存储**：运动曲线（关键帧 / 参数）；适用场景（3D / 2.5D / 平面）；样片
- **提交审查必填**：`spec.runtime`、`spec.params`
- **制作路线**：Three.js、2.5D 视差

### 转场 · `effect.transition`

两个镜头之间的过渡方式（视觉层面；剪辑逻辑见 structure.edit）。

- **例子**：3D 实景转黑底 2D 示意；遮罩擦除；缩放穿越；闪白；形状转场
- **存储**：实现代码；时长范围；适用条件；样片
- **提交审查必填**：`spec.runtime`、`spec.duration`
- **制作路线**：MG / Three.js

### 叠加与合成 · `effect.overlay`

多个画面层的组合方式：HUD 叠加、标注线、画中画、分屏、遮罩、跟踪贴图。

- **例子**：实景仿真 + 侧边遥测 HUD；高度标注竖线 9.2 m；画中画回放仿真；计时器叠加；三分屏
- **存储**：实现代码；层结构与插槽；跟踪 / 锚定方式；样片
- **提交审查必填**：`spec.runtime`、`spec.slots`
- **制作路线**：合成

### 3D 表现手法 · `effect.render3d`

3D 特有的表现：X 光透视、残影叠加、爆炸图、点云、线框、剖面、描边。

- **例子**：多次仿真残影叠加；爆炸图拆解；X 光透视；照片 → 点云 → 模型；卡通描边
- **存储**：实现代码（着色器 / 场景操作）；参数；适用模型要求（部件拆分等）；样片
- **提交审查必填**：`spec.runtime`、`spec.params`
- **制作路线**：Three.js

### 粒子与模拟特效 · `effect.particle`

烟、火、尘土、水、火花、喷气等粒子或程序化特效。

- **例子**：冷气喷口白雾；着陆扬尘；火花；雨雪
- **存储**：实现代码；确定性（种子）；参数；样片
- **提交审查必填**：`spec.runtime`、`spec.params`
- **制作路线**：Three.js / Canvas

### 后期处理 · `effect.post`

整体画面处理：调色 / LUT、颗粒、暗角、景深、动态模糊、辉光、色差、镜头光晕。

- **例子**：暗场高对比调色；胶片颗粒；景深模糊；辉光；运动模糊
- **存储**：实现代码或 LUT 文件；参数；前后对比
- **提交审查必填**：`spec.runtime`、`spec.params`
- **制作路线**：着色器、ffmpeg 滤镜

## 声音 · `sound`

听到的一切：配音、配乐、音效、环境声。

### 配音 · `sound.voice`

配音预设或录音：音色、语速、停顿、发音。

- **例子**：ElevenLabs 讲解男声预设；真人录音；角色配音
- **存储**：服务商与音色编号 / 录音文件；模型与参数；语速与停顿规则；发音词典；试听片段
- **提交审查必填**：`spec.provider`、`spec.sample`
- **制作路线**：ElevenLabs、录音

### 配乐 · `sound.music`

配乐：生成代码或音频，含情绪、BPM、调性、段落、分轨、节拍网格。

- **例子**：低电平科技铺底；蒙太奇推高段；片尾彩蛋轻快段
- **存储**：生成代码与参数（代码作曲）或音频文件；BPM、调性、情绪；段落结构；分轨；节拍网格；响度；试听
- **提交审查必填**：`spec.bpm`、`spec.mood`、`spec.sections`
- **制作路线**：代码生成、授权曲库

### 音效 · `sound.sfx`

点状音效：撞击、喷气、提示音、嗖声、读数跳动。

- **例子**：撞击声；冷气喷射；读数跳动滴答；转场嗖声；UI 点击
- **存储**：音频文件或合成代码；起音点（毫秒）；时长；类别；响度
- **提交审查必填**：`spec.category`、`spec.onset_ms`
- **制作路线**：代码合成、授权音效库

### 环境声 · `sound.ambience`

持续的环境底噪：城市、风、室内、太空嗡鸣。

- **例子**：城市车流；风声；机房嗡鸣
- **存储**：循环音频或合成代码；可循环点；情绪；响度
- **提交审查必填**：`spec.loop`、`spec.mood`
- **制作路线**：代码合成、授权素材

## 结构 · `structure`

组织时间的东西：叙事骨架、段落模式、节奏、剪辑手法。跨越多个镜头存在。

### 叙事骨架 · `structure.narrative`

整片的段落顺序与每段作用、时长占比。

- **例子**：结论先行 → 设定 → 问题 → 建模 → 反转 → 理论 → 佐证 → 彩蛋；三幕剧；问题 → 方案 → 证明（广告）
- **存储**：段落列表（名称、作用、时长占比、典型画面）；适用题材；参考片段映射
- **提交审查必填**：`spec.sections`
- **制作路线**：拆解、写作

### 段落模式 · `structure.segment`

可复用的局部结构：开头钩子、方案对比、理论回到仿真验证、历史证据链。

- **例子**：结论先行钩子（7 秒）；方案一 → 加一项代价 → 方案二反转；人物 + 论文 + 年份 + 原话的证据链
- **存储**：节拍列表；每拍的画面与旁白要求；时长；参考片段
- **提交审查必填**：`spec.beats`
- **制作路线**：拆解

### 节奏模板 · `structure.rhythm`

剪辑节奏的数值规则：段时长分布、切点密度、蒙太奇节奏、与旁白和音乐的对齐方式。

- **例子**：段时长中位 2.2 秒；蒙太奇每镜 0.43 秒；41% 切点落在停顿里
- **存储**：段时长分布；每分钟视觉边界；对齐规则（停顿 / 节拍）；测量来源
- **提交审查必填**：`spec.metrics`
- **制作路线**：拆解测量

### 剪辑手法 · `structure.edit`

剪辑逻辑：J-cut、L-cut、匹配剪辑、跳切、快剪蒙太奇、硬切、留白。

- **例子**：火箭着陆快剪蒙太奇；匹配剪辑；J-cut 声音先入；跳切
- **存储**：定义；使用条件与约束（可校验）；示例片段
- **提交审查必填**：`spec.definition`、`spec.constraints`
- **制作路线**：剪辑

## 拆解记录 · `reference`

一整条参考视频的拆解：元信息、逐段分析、关键帧，以及从它拆出来的全部素材条目。不存原视频。

### 参考视频拆解 · `reference.video`

对一条参考视频的完整拆解记录。

- **例子**：《汽车飞出高架，怎样才能软着陆？》拆解
- **存储**：元信息（标题、链接、作者、时长、规格）；转写；切点与节拍；色彩与响度统计；逐段拆解（结构 / 风格 / 效果 / 素材 / 声音）；关键帧（低清，内部参照）；派生条目清单
- **提交审查必填**：`spec.meta`、`spec.segments`
- **制作路线**：拆解
