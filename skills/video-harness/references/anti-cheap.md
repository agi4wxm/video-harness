# 反廉价清单

来自参考分析和反面样本（`eval/negatives/battery-80`：节奏、字号、动效指标全部落在参考区间内，看起来仍然廉价）。复核 J5 逐条对照；简报的 `Banned:` 从这里按题材挑。

## 通用（讲解 / 科普）

| 廉价的样子 | 原因 | 怎么改 |
|---|---|---|
| 灰暗、接近灰度的画面 | 彩度太低（反面样本 C 中位 0.008，插画讲解类约 0.11） | 明亮底色 + 高彩度主色，按章节换色板 |
| 满屏是字 / 每句话都上字幕 | 信息靠读，不靠看 | 文字在屏 ≤ 40% 时间，以指向物体的小标签为主，数字用大字 |
| 抽象的框和箭头 | 没有视觉想法 | 屏幕上的东西都"是某个东西"：器官、细胞、人群、工具 |
| 界面 / 卡片 / 窗口感 | 积木是 UI 组件，不是场景 | 用场景：插画世界 + 虚拟相机 |
| 一镜一个样 | 没有设计体系 | 固定语义色和母题；同一章节同一色板 |
| 画面一动不动 | 没有"生命" | 角色呼吸眨眼、背景漂移、视差、缓慢推镜 |
| 跟着字切、不停顿 | 节奏不呼吸 | 一句话说完、换口气，画面再换；旁白里留停顿 |
| 线性缓动、同时好几处在动 | 动效没有主次 | 缓出 / 弹簧；同一时刻只有一个运动焦点 |
| 辉光到处都是 | 强调失效 | 辉光只给重要的东西 |
| 无意义的粒子、光斑 | 装饰抢焦点 | 删掉，或让粒子表达"流动"这种具体含义 |

## 按题材的 Banned 示例

- **插画科普**：`Banned: 灰暗低彩度、整屏文字、界面卡片感、抽象框箭头、线性缓动、无意义粒子、每镜换风格`
- **数据新闻**：`Banned: 3D 饼图、彩虹色阶、无单位数字、没有出处的数字、一屏多于 3 组数字`
- **产品发布**：`Banned: 辉光、弹跳缓动、粒子、模板感光效、替代品 logo`（产品发布禁辉光，插画科普反而大量用辉光——禁用清单必须按题材分）
