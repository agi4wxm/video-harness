# 质量规范

质量分三层，谁判定写得很清楚：

| 层 | 判定 | 不通过 |
|---|---|---|
| **H 硬约束** | `vh check`（代码） | 不能进入下一阶段 / 不能出成片 |
| **简报约定** | 简报里的设计包、语义色、母题、Banned 清单；复核时逐条对照 | 复核问题（P0–P2） |
| **审美** | 看图复核（全新上下文）+ 用户 A/B | 修复 ≤ 3 轮，之后交给用户 |

与参考视频的统计比对（`vh compare`）是**诊断**：偏离 1.5 倍以上提示你去看，但不作为闸门——数字全落在参考区间里的片子照样可能很廉价。

## H · 硬约束（`vh check`）

| ID | 内容 | 阶段 |
|---|---|---|
| H1 | 成片规格：分辨率 / 帧率与 `vh.json` 一致（默认 1920×1080 @30），H.264 + AAC，时长与分镜一致（± 1 帧） | render |
| H2 | 确定性：本地 / html / react 镜头里没有随机数、系统时间、计时器、CSS 动画、网络请求 | build |
| H3 | 颜色只用 token：积木参数里不写 hex；本地镜头写死 hex 会警告 | storyboard / build |
| H4 | 文字在安全区内 | layout |
| H5 | 文字之间重叠不超过较小框的 10% | layout |
| H6 | 字高 ≥ 画面高 2.5%；对比度大字 ≥ 3、其余 ≥ 4.5 | layout |
| H7 | 每组文字在屏时间 ≥ max(0.8s, 阅读时间)（警告） | layout |
| H8 | 画面静止 ≤ 4s | layout |
| H9 | 响度 -14 ± 1 LUFS，真峰值 ≤ -1 dBTP | render |
| H11 | 镜头首尾相接、覆盖全部配音；节拍在镜头区间内 | storyboard |
| GATE | 简报 `status: approved`、分镜 `approved: true`（人工确认） | brief / storyboard |
| M4 | 每句话开头 0.8s 内有节拍或切镜（警告） | storyboard |

版面类校验（H4–H8）直接读场景图，不需要 OCR；html 镜头导出 `inspect(t)` 时也纳入，react 镜头跳过。
