# 插画科普（横屏讲解）的原则

来源：对一条约 12 分钟的高播放量插画科普片（扁平矢量 2D 动画，60fps）的测量 + 全片抽帧通看。**借鉴的是原则，不复刻任何频道的角色和视觉标识。**

## 测量结论（与竖屏快节奏 MG 对比）

| 指标 | 插画科普 | 竖屏快节奏 MG |
|---|---|---|
| 段时长中位 | **3.4s**（P10 1.5 · P90 7.3） | 2.4s |
| 视觉边界 / 分钟 | 14.9 | 21.5 |
| 停顿 / 分钟 | **21.5**（中位 0.52s） | 1.7 |
| 画面变化落在停顿里 | **44%** | 约 1% |
| 对齐短语边界（相对随机） | 1.96 | 1.34 |
| 对齐音乐节拍 | 与随机无差异 | 与随机无差异 |
| 画面亮度 L 中位 | 0.62 | 0.41 |
| 画面彩度 C 中位 | **0.113** | 0.012 |
| 有文字的时间 | 35%（全是标签，无字幕） | 80%+，全程字幕 |

**节奏是呼吸式的**：话说完一句、换口气，画面才换；每个画面停得更久、信息更足。快节奏 MG 是"字不停、图不停"。两种都成立，但不能混用。

## 设计体系

- 扁平矢量、无描边、圆角；质感来自柔和渐变 + 辉光 + 轮廓光。
- 屏幕上的元素都是"某个东西"（器官、细胞、分子、针管、人群），几乎没有抽象框和箭头。
- **按章节换整套颜色**：个人故事暖色；历史闪回棕褐 + 复古画框 + 颗粒暗角；体内机制深紫 / 藏青 / 洋红。
- **语义编码**：药物从头到尾是同一种霓虹绿；观众不读字也知道谁是谁。
- 角色与拟人：贯穿全片的主角；器官、细胞拟人化，情绪靠表情传达。

## 连续性手法

推镜 + 换光（不切镜完成情绪转变）· 尺度穿越（身体 → 细胞 → DNA 一路缩放）· 跟拍运镜 · 母题反复（同一个"锚点镜头"出现三次）· 始终有生命（呼吸、漂移、视差）· 结尾回顾蒙太奇。

## 剪辑

章节标题卡（字体风格与正文不同）· 分屏网格 · 年代感闪回 · 在停顿处换画面 · 3–8s 长镜头 + 镜头内动作。

## 视觉想法（概念 → 画法）

生存率 → 一群小人中有多少变绿 / 满屏点阵 + 大数字 · 剂量实验 → 一排针管对一排小鼠 · 疗程进度 → 人体图 + 按周进度条，病灶逐个熄灭 · 药物流动 → 身体变成发光的线框网格 · 程序性死亡 → 倒计时秒表 · DNA 修复 → 像小工人一样干活的分子 · 可信度 → 角落里的小字文献引用。
