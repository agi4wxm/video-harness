# 竖屏快节奏 MG 口播的原则

来源：4 条同一作者的竖屏科技口播（150–180s）+ 1 条横屏物理讲解的测量。当前默认画幅是横屏；做竖屏时参考这里。

- **固定版式模板**带来强识别度：窗口内容区（约占画面 40%）+ 窗口内字幕条 + 底部常驻话题栏。分析这类视频必须先做版式检测，否则切镜、纹理统计都被模板稀释（`vh_analyze` 已处理）。
- **节奏**：约 340 字 / 分钟、几乎不停顿；画面约每 2.4s 变一次，硬切只占视觉变化的约 40%，其余是同一镜头内的 MG 场景切换（视觉节拍）。不卡字、不卡音乐节拍；对齐短语边界相对随机约 1.34 倍。
- **一句话一画面的直译**：用素材或简洁图解把每个名词画出来；原理部分用黑底极简 MG 图解，讲完马上回到生活化画面。
- **动效**：文字入场中位 0.43s，约 30% 直接出现；80% 带滑入，以从下进入最多。
- **方法教训**：MG 的节奏单位是视觉节拍而不是硬切；所有对齐类指标都要和随机基线比较（中文逐字时间戳很密，"离字边界很近"没有意义）；运动强度与语音能量无关（r ≈ 0.07），不要当规则。
- **横屏物理讲解**里可借鉴的手法：半透明轨迹叠加表达"模拟了几百次"、X 光透视揭示内部、公式逐项追加并变色、年份滚动配刻度尺、在论文配图上描线揭示答案。
