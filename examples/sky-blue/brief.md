# 创意简报：Why is the sky blue?（示例）

## inputs
- 题目：为什么天空是蓝色的；观众：好奇的普通人；时长约 34 秒；语言：英文，ElevenLabs 配音（George）。
- 事实：瑞利散射强度约与波长四次方成反比，蓝光（~450nm）比红光（~700nm）散射强约 5–6 倍；日落时光程更长。

## direction
- 插画世界设计包：白天章节明亮奶油底 + 蓝天；放大到分子后换夜间章节（深紫底，光更显眼）；日落用棕褐章节。
- 语义色：sky = 天蓝，blue = 散射蓝光，red = 红光，全片固定。
- 母题：太阳（开头、比喻图、日落）、氮气分子（放大终点、散射主角）。
- Banned: 灰暗低彩度画面、整屏文字、界面卡片感、线性缓动、无意义粒子、每镜换一种风格。

## structure
钩子 0–5.5s（矛盾：天是蓝的，阳光是白的）→ 问题卡 → 放大到分子 → 散射（核心机制 + 数字）→ 比喻图收束 → 日落作为反例验证。每句话之间有停顿，画面在停顿处换。

## build
- 积木：character-scene、title-card、scale-zoom、process-diagram。
- 本地场景图 `shots/scatter.ts`：散射机制（光子方向与颜色比例都由种子决定）。
- html 镜头 `shots/sunset/`：Canvas 日落，演示 seek(t) 约定。
- 不使用生成式图片或视频。

## gotchas
- 文字只做指向标签，不配字幕；数字（×5）用大字。
- 放大镜头要一镜到底，不要切。

## start
先给节拍表（每拍的视觉想法），确认后写场景代码。
