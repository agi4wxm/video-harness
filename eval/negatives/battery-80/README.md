# 反面样本：battery-80

旧架构（竖屏、固定窗口版式、界面组件式积木）做的 19 秒演示片的拼图。保留它是因为它证明了一件事：

> 节奏（视觉边界 21.9 / 分钟）、字幕字高、入场时长、直接出现占比、画面彩度——**所有统计指标都落在参考视频的 P10–P90 区间里**，成片仍然显得廉价。

原因（见 `skills/video-harness/references/anti-cheap.md`）：画面接近灰度（彩度 C 中位 0.008）、整屏都是字、积木是界面组件而不是场景、没有母题和语义色、没有停顿的呼吸节奏。

由此得到的设计决定（`docs/decisions.md` D2）：统计区间只做诊断；质量靠简报约定 + 看图复核 + 用户 A/B。复核 J5 题对照本样本。
